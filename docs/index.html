XChat Cerulean

A native IRC client for Apple Silicon.

This is a fork of X-Chat Aqua. It is not endorsed by or affiliated with the original authors.
View on GitHub Changelog

Why this exists

X-Chat Aqua stopped moving in 2017. It no longer compiles: it expects a 2013 snapshot of glib, OpenSSL 1.0, CocoaPods, and a Crashlytics SDK that was switched off in 2020. With Apple winding down Intel support, an Intel-only client that cannot be built is a client that quietly disappears.

Cerulean rebuilds it on current foundations so it keeps working.

What changed

Apple Silicon native

arm64, built against the current SDK, targeting macOS 26.

TLS that actually verifies

The old build sent no SNI and never checked the certificate matched the host, so any valid certificate passed. Both fixed.

Modern libraries

Homebrew glib 2.88 and OpenSSL 3 replace the vendored 2013 glib and OpenSSL 1.0.

No CocoaPods

Fabric and Crashlytics are gone. Building needs Xcode and Homebrew, nothing else.

Notifications restored

Rebuilt on UserNotifications, with inline replies. The old API was removed by Apple.

Lighter tree

The GTK and terminal front-ends, the iOS port and 103MB of vendored Perl headers are gone.

Build it

Requires Xcode and Homebrew.

brew install glib gettext openssl@3

git clone https://github.com/vdmkenny/xchataqua.git
cd xchataqua
xcodebuild -project XChatAqua.xcodeproj \
  -scheme 'XChat Cerulean' -configuration Release build

Settings live in ~/Library/Application Support/XChat Cerulean/. Old X-Chat Aqua configuration is not read automatically; copy it across before first launch if you want to keep it.

A note on how this was built

This port was carried out using an LLM (Claude). The app builds, launches and connects, but it has not had the long-tail human testing the original accumulated over the years. Bug reports are welcome.
